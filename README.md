## About

**MERN Ecommerce Product Management App** is a full-stack web application built with **MongoDB, Express.js, React.js, and Node.js**.

The application provides a complete product management system where users can add, view, search, update, and delete ecommerce products through a modern and responsive dashboard.

---

## Features

- 📦 Add new products
- 👀 View all products
- 🔍 Search products
- ✏️ Update existing products
- 🗑️ Delete products
- 🖼️ Upload product images
- ⭐ Product ratings
- 💰 Price and currency management
- 🚚 Free shipping status
- 📊 Product statistics
- 📱 Responsive design
- 🔗 REST API integration
- 🗄️ MongoDB database integration

---

## Application Flow

**Add Product** → Enter product details and upload an image.

**Product Dashboard** → View all products and product statistics.

**Search Products** → Quickly find products from the dashboard.

**View Product** → Open and review complete product information.

**Update Product** → Edit existing product information and save changes.

**Delete Product** → Remove products from the database.

**MongoDB** → Product data is stored and managed through MongoDB.

---

## Product Management Workflow

### 1. Add Product

Users can enter product information such as name, price, currency, sales, rating, shipping status, shop name, and product image.

### 2. Product Dashboard

All products are displayed in a responsive dashboard where users can view product information and statistics.

### 3. Search Products

Users can quickly search for products from the dashboard.

### 4. View Product

Users can inspect complete information about an individual product.

### 5. Update Product

Existing product information can be edited and updated.

### 6. Delete Product

Products can be permanently removed from the database.

### 7. MongoDB Integration

Product data is stored and managed through MongoDB using the Express.js backend.

## Getting Started

Follow the steps below to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- MongoDB or MongoDB Atlas
- Git

---

## Clone Repository

Clone the repository to your local machine.

    git clone https://github.com/Abdullah-Asim-dev/Mern-Ecommerce-App.git

Move into the project directory.

    cd Mern-Ecommerce-App

---

## Backend Setup

Navigate to the backend directory.

    cd Backend

Install the backend dependencies.

    npm install

Create a `.env` file inside the `Backend` folder.

    MONGODB_URI=your_mongodb_connection_string
    PORT=3000

Start the backend server.

    node server.js

The backend server will run on:

    http://localhost:3000

---

## Frontend Setup

Open a new terminal and navigate to the frontend directory.

    cd Mern-Ecommerce-App/Frontend

Install the frontend dependencies.

    npm install

Start the development server.

    npm run dev

Vite will provide the local development URL in the terminal.
